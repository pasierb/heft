# `heft` project instructions for coding agents

## Project management - Fizzy

This project is using Fizzy - a kanban board software. When you're asked to work on ticket / issue / card
it most likely refers to fizzy. Use fizzy skill to interact with fizzy app.
When asked to work on specific card make sure that is not already in progress - if so, ask to confirm whether
working on it is desirable.
Make sure to update to status accordingly, i.e. "Doing" and "Done".
"Doing" is for when you started working on card.
"Done" when PR / code is merged into main branch.
